# Cursor Landing Page Clone ⚡

A modern **HTML & CSS clone of the Cursor landing page**, built to practice dark-theme UI design, gradients, and responsive layouts — without JavaScript.

---

## 🚀 Live Demo

🔗 **Deployed Link:**  
https://cursor-html-css.vercel.app/

---

## 🧩 Sections Recreated

- Header / Navigation bar
- Hero section with cta
- "Trusted By" section
- Product highlights
- Feature grid
- Review section
- Recent highlights
- Footer

---

## 🧰 Tech Stack Used

- **HTML5** – Page structure
- **CSS3** – Styling and theming
- **Flexbox** – Layout alignment
- **CSS Grid** – Feature layouts
- **Vercel** – Deployment

> ⚠️ Built using **only HTML and CSS** — no JavaScript.

---

## 🎨 Fonts and Colors Used

### Fonts
- Primary: CursorGothic, "CursorGothic Fallback", system-ui, "Helvetica Neue", Helvetica, Arial, sans-serif

### Colors
| Purpose | Color |
|------|------|
| Background | `#111` |
| Primary Text | `#c4c3c3` |
| Secondary Text | `#a8350b` |
| Hover | `#211f17` |
